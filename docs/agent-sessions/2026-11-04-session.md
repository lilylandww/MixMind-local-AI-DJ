## Platform notes (Linux host, different from the plan's macOS assumptions)

1. **Worker-group tests**: `demucs` + `mlx-whisper` (opt-in `worker` group) can't install on Linux (`mlx` is Apple-silicon-only); the 4 test files importing them errored at collection. conftest now ignores exactly those files when their deps are missing — macOS workers still run everything.
2. **DB bootstrap**: fresh dev Postgres needs `uv run alembic upgrade head` once before pytest (the dockerized backend does this in its entrypoint; host pytest does not).
3. **Docker backend image won't build on this host**: `uv sync` inside the image needs ~12 GB in one layer (torch + CUDA stack via `kokoro`); disk had ~8 GB. Freeing npm/builder caches got to 9.5 GB — still short. E2e ran the backend + worker natively from `backend/.venv` instead (identical code paths; ffmpeg on PATH). On a machine with disk headroom `docker compose up -d --build` should work unchanged.
4. **Full mix render not verifiable here** (needs demucs+mlx native worker or Modal GPU). Pipeline logic is covered by the mocked suite (all green); live run verified through `analyze` and the graceful `failed` + `error_text` path.
5. Static `ffmpeg` 7.0.2 installed to `~/.local/bin` (no sudo on this box).
